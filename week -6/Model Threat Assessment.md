# DataForge ML — Model Security Assessment

| Field                         | Your Finding                                                                                                                                                                                                                                                                                                                                                                |
| ----------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Model File**                | `genomics_analyzer_v2.pkl`                                                                                                                                                                                                                                                                                                                                                  |
| **Source Repository**         | `logix-community/genomics-analyzer-v2` — Hugging Face                                                                                                                                                                                                                                                                                                                       |
| **Serialisation Format**      | Python Pickle (`.pkl`)                                                                                                                                                                                                                                                                                                                                                      |
| **Threats Detected**          | PickleScan reported **1 infected file**, **0 suspicious globals**, and **1 dangerous global**. The scan did not provide the name of the dangerous global.                                                                                                                                                                                                                   |
| **Threat Type**               | Unsafe deserialization / potentially dangerous pickle content                                                                                                                                                                                                                                                                                                               |
| **Supply Chain Risk Factors** | The application retrieves the model from an external Hugging Face repository and loads it using Python's `pickle.load()`. A compromised model artifact could therefore introduce executable behavior into the application environment. PickleScan identified a dangerous global within the artifact.                                                                        |
| **Business Impact**           | **High.** If the dangerous pickle content is exploitable during deserialization, an attacker could potentially execute code with the privileges of the application process. This could expose application data or secrets, alter application behavior, or compromise the hosting environment.                                                                               |
| **Remediation Plan**          | Do not deserialize the artifact until the PickleScan finding has been investigated. Verify the model's provenance and integrity, pin the application to a trusted model version, scan model artifacts before deployment, and isolate model loading from sensitive resources. Where feasible, migrate to a model format that does not rely on Python pickle deserialization. |
